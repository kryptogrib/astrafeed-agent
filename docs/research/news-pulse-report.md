# News-first Pulse: отчёт о готовности (2026-09-24)

Отчёт по [плану](../plans/news-first-pulse-agent-prompt.md). Готовность к демо **не достигнута
полностью**: на замороженной выборке не выполнены пороги точности отбора, объединения событий и
связей «комментарий → событие». Ниже — что сделано, результаты и причины.

## Что реализовано

- Конвейер `docs/research/news_pulse_*.py`: read-only снимок БД → сегменты поста (событие, позиция
  автора, перепечатка, реакция, промо) → LLM-классификация с кешем → группировка событий →
  связи комментариев → `pulse.json`, `brief.md`, `decisions.json`, `manifest.json`.
- События группируются жадными кликами без транзитивных склеек: детерминированные ключи
  (действие, объект, сумма в млн USD, дата с разрешением «вчера/сегодня») и LLM-судья на парах-
  кандидатах. Разные ETF (BTC/ETH), разные дни потоков и разные суммы — конфликт.
- Строки таблиц потоков ETF получают заголовок таблицы как контекст.
- Тема, упомянутая как фон (сравнение, цель свопа, риторический вопрос), не становится событием темы
  (`topic_role=context`).
- Обсуждение: только комментарии, называющие тему, или комментарии к постам с упоминанием темы.
- Распространение считается по уникальным публикациям: каналы, первоисточники, перепечатки.
- Бриф извлекающий: утверждения — дословные цитаты, числа считает код. Проверка
  `news_pulse_ground.py` сверяет каждое утверждение с БД; она подключена к оценке.

- `aave 2026-09-09..2026-09-23`: 3 события, авторские позиции, бриф; подтверждённость 100%.
  Ошибка: «Aave Proposes Custodied Collateral Lending» и «Aave предлагает займы под кастодиальный
  BTC», вероятно, одно событие, но не объединены; пост «Aave V4 $145M» не выделен как событие.

## Оставшиеся ошибки (по news-eval; код под них не настраивался)

- Отбор: 5 постов по zec отнесены к новостям вопреки разметке (дайджесты и рекап-посты).
- Объединение: пересказы одного события разными словами без общей суммы/даты не склеиваются
  (pair-01, 02, 04, 08, 09); ложная склейка pair-12 — два поста markettwits об ETH с похожими ключами.
- Связи комментариев: реплики о тезисе автора поста привязываются к событию поста (4 из 4).
  Нужен отдельный шаг «комментарий к событию или к мнению автора».
- Выборка маленькая: это проверка демо, а не качества на всех данных.

## Воспроизведение

```bash
make news-pulse PULSE_DB=astrafeed.db TOPIC=zec WINDOW=2026-09-17..2026-09-19   # JSON + бриф
PULSE_REUSE=1 make news-pulse TOPIC=aave WINDOW=2026-09-09..2026-09-23          # только из кеша
make news-pulse-serve PULSE_DB=astrafeed.db   # GET /news-pulse?topic=zec&window=2026-09-17..2026-09-19
make news-pulse-eval PULSE_DB=astrafeed.db    # итоговая оценка → artifacts/news-pulse/eval
make news-pulse-tune PULSE_DB=astrafeed.db    # настроечная → artifacts/news-pulse/tune-eval
make news-pulse-ground PULSE_DB=astrafeed.db  # подтверждённость → artifacts/news-pulse/grounding
uv run pytest -q && uv run ruff check src tests
```

`deepseek/deepseek-v4-flash`, ответы в `artifacts/news-pulse/cache`, лимит $3 на прогон.
