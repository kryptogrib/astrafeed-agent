# Инструкция для ручной разметки треда (Pulse, контракт v2)

Лист: `pulse_label_sheet_<post>.tsv`. В нём только текст треда; предсказаний модели и предварительной
агентской разметки там нет, чтобы не подсказывать. Тема — ETH. Заполните колонки справа от `text`.
Авторы обезличены (u1, u2…). `reply_to`: `post`, id комментария или `missing:<id>` — родитель не
сохранился в базе, судите без него.

| колонка | что писать |
|---|---|
| topic_relation | `direct` — в самой реплике есть название или алиас ETH (эфир, eth, ether…); `contextual` — реплика про ETH, но это видно только из поста или сообщения, на которое она отвечает; `unrelated` — другой предмет; `unclear` — данных не хватает |
| mention | только для direct: точный фрагмент текста с названием («eth», «эфире») |
| subject | о чём реплика, 2–5 слов своими словами («цена минта», «температура видеокарты»); пусто для приветствий и перепалки |
| evidence_ids | через запятую: для direct — свой id; для contextual — `post` и/или id предков, которые дают связь с ETH; для unrelated — `post`/предок, чью тему реплика продолжает (так помечается «связанное обсуждение»); пусто, если реплика начинает новый предмет |
| aspect | только для direct/contextual: `market` (цена, торговля, цикл, ликвидации), `payment` (ETH тратят: цена покупки, газ, баланс кошелька), `technology`, `other` |
| claim | конкретный тезис, к которому реплика занимает позицию, одним утверждением («минт уже невыгоден»); пусто, если тезиса нет (шутка, голый вопрос, факт без позиции) |
| stance | позиция к claim: `support` / `oppose` / `mixed` / `unclear`. Не настроение к ETH. Пустой claim или двусмысленный сарказм → `unclear` |
| borderline | `1`, если сомневаетесь |
| note | почему так, особенно для спорных |

Правила:
- Реплика не становится «про ETH» только потому, что пост про ETH. Смотрите цепочку ответов.
- Ответ на офтоп может сам вернуться к ETH — судите по его тексту.
- Цена, названная в ETH, — это не обязательно payment: payment, когда ETH тратят или его не хватает на оплату.
- `[media]` — картинку не видно. `unclear` ставьте, только если без неё смысл не понять.
- Не заглядывайте в выход модели и в предварительную агентскую разметку до окончания.
