# Проверка комментариев

Открыть `artifacts/comment-review/comment-review.html` в браузере. Страница автономна, сервер не нужен.

В подготовленной выборке 100 реальных комментариев: 60 случайных, 20 дополнительных из ETH-треда и 20 из конкурса. Случайная группа может также содержать сообщения из этих тредов; повторов ID нет. Группы сохраняются при экспорте и не должны смешиваться при оценке частоты ошибок.

Все комментарии предварительно размечены Codex по доступному тексту поста, комментария и родительского ответа. Это **не результаты производственного классификатора и не человеческий эталон**. Начальный счётчик проверки — 0/100. Отсутствующие вложения не интерпретировались: неопределённость отмечена явно. Исходные утверждения пользователей не проверялись на достоверность.

Проверка: прочитать контекст и объяснение Codex → «Всё верно» либо исправить поля → сохранить. Можно добавить несколько тем, удалить все темы, отдельно указать шум, тип и отношение. Пустой аргумент допустим. `unknown` не равен `neutral`. `bull`/`bear` здесь означают положительное/отрицательное отношение к теме, не обязательно торговый прогноз. Смешанная оценка сохранена как `unknown` с пояснением. Шум может иметь явные упоминания токенов: их нельзя включать в содержательную плотность без фильтра по `noise`.

`←`/`→` переключают карточки вне полей ввода; `Ctrl/⌘ + Enter` сохраняет проверку. Изменение полей возвращает запись в черновик. Разметка автоматически сохраняется в localStorage, но для переноса/резервной копии нужно нажать «Экспорт JSON». В экспорт входят оригиналы, предварительная разметка и отдельное человеческое решение. База SQLite не изменяется. Импорт чужой выборки или конфликтующих решений отклоняется, чтобы не перезаписать работу молча.

## Пересборка

Из корня: `python3 tools/comment-review/build.py`. Чтение БД только в режиме read-only, выборка с фиксированным seed. Если есть `artifacts/comment-review/predictions.json`, разметка встраивается по ID, а контрольная сумма проверяет неизменность исходного текста и контекста. Новая выборка может содержать другие записи: для них не выдумываются предсказания. HTML и данные корпуса оставлены локальными и исключены из git.

## Формат загрузки предсказаний

Кнопка принимает JSON (на новые, ещё не изменённые записи):

```json
{"items":[{"id":"comment_key из выборки","prediction":{"mentions":[{"topic":"ETH","sentiment":"unknown","argument":""}],"noise":"substantive","kind":"question"}}]}
```

`sentiment`: `bull`, `bear`, `neutral`, `unknown`.
`noise`: `substantive`, `giveaway`, `ad`, `flood`, `other`, `unknown`.
`kind`: `opinion`, `question`, `complaint`, `other`, `unknown`.

Это локальный формат проверки; адаптер к будущему классификатору отдельно не реализован. Повторная загрузка предсказаний поверх существующих запрещена. Человеческая разметка не записывается обратно в production-таблицы.
