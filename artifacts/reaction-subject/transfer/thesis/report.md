# Извлечение авторских тезисов на transfer — регрессионный эксперимент

Не holdout: выборка и старые метки уже просмотрены. Разметка тезисов — предварительная, одного агента, зафиксирована в `3a4c52a` **до** чтения ответов извлекателя и связывателя B. Старый `labels.jsonl` не редактировался. Production не менялся.

Вопрос: появится ли конкретная связь «комментарий → тезис», если отдельно извлечь 0–3 авторских тезиса с id и дословной цитатой.

## Итог

На 16 ожидаемых конкретных thesis-связях добавилось **4 верных** и **2 ложных**. Цена этого шага **$0.00993** новых вызовов (extract $0.00389 + B $0.00604). Event-связи с id на ветке context+id+verify не изменились (1 верная, 0 ложных). Это не обещание внедрять извлекатель: полнота конкретных связей 4/16, извлечение попало в 10 из 41 ожидаемого тезиса и дало 14 лишних.

## Дизайн

- **A:** сохранённый transfer v2, тезисов в посте 0. Промпт, id-контракт и верификатор без изменений.
- **B:** тот же v2, в контекст добавлены только тезисы, прошедшие `quote == post[start:end]` (неверный offset модели чинится, только если цитата встречается в посте ровно один раз; двусмысленная — отказ).
- Извлекатель видит только `requested_topic` и пост. Комментарии и метки в payload нет (`author_thesis_extract.check`).
- Сопоставление: `gold_id` ↔ извлечённый `th-<sha>` по пересечению границ и вложенности слов. Id модели отбрасывается. Совпадение класса `author_thesis` не засчитывается. Старый `target_id=null` не делает новый id ошибкой сам по себе.
- Две старые thesis-метки (Pendle 151360/151362) помечены как **несвязываемые**: комментарий спорит с питчем Pendle, не с выводом автора.

## Проверки

- payload извлекателя: только `post`, `requested_topic`; 0 утечек комментариев/меток.
- у всех 24 принятых тезисов `post[start:end] == quote`; чужой id связыватель отклоняет (тест + check).
- id стабилен от url+цитаты, не от модели.
- в контексте B нет более поздних реплик (`leaks` на 112).
- md5 старых labels/threads/baseline/snapshot/v2 llm+verify совпали с протоколом.
- обе БД не записывались.
